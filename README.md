## 使用 HTML 簡報

下載完整專案後，用瀏覽器開啟 `slides/pdpa/index.html` 即可，無須安裝套件。請保留資料夾相對位置，讓 Wiki、講義與圖片連結正常運作。

支援方向鍵翻頁、章節目錄、解析展開與列印。完整操作說明見 [簡報說明](slides/pdpa/README.md)。GitHub 原始碼頁面不會直接執行這份 HTML，需下載後在本機開啟。

若要修改內容，編輯 `slides/pdpa/content.mjs`，再使用 Node.js 執行：

```powershell
node slides/pdpa/build.mjs
```

## 目前教學製作階段

現有 HTML 為初學者教學簡報。Graph 版本已完成大綱確認及逐頁內容提案，逐頁內容待確認；下一階段為知識地圖、概念教學及案例回讀三種代表頁原型。

後續流程依序為大綱確認、逐頁內容確認、原型確認、完整製作與檢查。依既有專案結構維護，不另建專案。
